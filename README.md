

\# Mi Proyecto Web



\## Descripción



Este proyecto consiste en una página web básica desarrollada

en HTML para aprender a utilizar Git y GitHub.



Se han utilizado repositorios locales y remotos, ramas independientes,

commits y Pull Requests.



\## Tabla de contenido



1\. \[Instalación](#instalación)

2\. \[Estructura del proyecto](#estructura-del-proyecto)

3\. \[Mejoras implementadas](#mejoras-implementadas)



\## Instalación



Para ver el proyecto se puede clonar el repositorio:



git clone https://github.com/aduarterb-cyber/Proyecto1.git



Una vez descargado, abrir el archivo index.html con un navegador web.



\## Estructura del proyecto



\- index.html: página web principal.

\- .gitignore: excluye la carpeta .vscode.

\- README.md: documentación del proyecto.



\## Mejoras implementadas



\### 1. Menú de navegación



Se ha añadido un menú de navegación con enlaces internos a las secciones

Inicio y Contacto.



Esta mejora se desarrolló en la rama feature/menu

y se fusionó con main mediante el Pull Request #1.



\### 2. Tabla de horarios



Se ha incorporado una tabla HTML con información del horario de las clases.



También se añadió un enlace a la tabla desde

el menú de navegación.



Esta mejora se desarrolló en la rama feature/tabla

y se fusionó con main mediante el Pull Request #2.
